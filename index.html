สถานะรถ

ตำแหน่งจริงมาจากไหน

แผนที่ในหน้านี้วาดเองและขยับรถตามเส้นทางสมมติ เพื่อให้เห็นรูปแบบหน้าจอ ระบบจริงใช้แผนที่ Google Maps กับตำแหน่งจริงจากแหล่งใดแหล่งหนึ่งด้านล่าง

แนะนำGPS ติดรถ
  • ส่งตำแหน่งต่อเนื่องแม้ปิดหน้าจอ
  • ดึงเข้าชีตทุก 30–60 วินาทีผ่าน API หรือ webhook
  • ต้องตรวจว่ายี่ห้อที่ใช้เปิด API ให้หรือไม่
ได้ผลใกล้เคียงแอปเรียกรถที่สุดแอปมือถือ
  • เก็บตำแหน่งได้ขณะหน้าจอดับ
  • ต้องพัฒนาเป็นแอป ใช้งบและเวลามากกว่าเว็บ
ทำได้ทันที แต่มีข้อจำกัดหน้าเว็บนี้ (Geolocation)
  • ส่งตำแหน่งเฉพาะตอนเปิดหน้าไว้และอนุญาตตำแหน่ง
  • หน้าจอดับหรือสลับแอป เบราว์เซอร์มักหยุดส่ง
  • เหมาะกับบันทึกจุดเริ่มและจบเที่ยว

ผู้ใช้งานและรหัสเข้าระบบ

กำหนดรหัส 6 หลักรายบุคคล แต่ละคนต้องมีรหัสไม่ซ้ำกัน

บทบาทหัวหน้างาน
  • เห็นทุกเมนู ทั้งแดชบอร์ด รายงาน และแผนที่
  • เพิ่ม แก้ไข ลบยานพาหนะ และกำหนดอัตราสิ้นเปลืองมาตรฐาน
  • เพิ่มผู้ใช้ ตั้งรหัสใหม่ ปิดการใช้งาน
บทบาทลูกน้อง
  • บันทึกการเติมเชื้อเพลิง ชื่อผู้ขับเป็นชื่อตัวเองเสมอ
  • ดูแดชบอร์ด รายงาน แผนที่ และประวัติของทุกคนในกลุ่ม
  • ไม่เห็นเมนูจัดการรถและผู้ใช้

เชื่อมกับ GPS หรือ Google Maps ได้ไหม

ได้ ทำได้เป็นสามระดับ เริ่มจากระดับ 1 ก่อนได้โดยไม่ต้องซื้ออุปกรณ์เพิ่ม

ระดับ 1 · ตรวจสอบด้วย MapsGoogle Maps Routes API
  • กรอกต้นทางและปลายทางของแต่ละเที่ยว ระบบคำนวณระยะทางตามถนนจริง
  • เทียบกับระยะทางจากเลขไมล์ ถ้าต่างกันมากให้แจ้งเตือน
  • ต้องมี API key และมีค่าบริการตามปริมาณการเรียกใช้
ระดับ 2 · GPS จากมือถือบันทึกเส้นทางด้วย Geolocation
  • แมสเซ็นเจอร์กดเริ่มและจบเที่ยวในหน้าเว็บ ระบบเก็บพิกัดระหว่างทาง
  • ต้องอนุญาตตำแหน่งและเปิดหน้าไว้ ความแม่นยำขึ้นกับเครื่อง
  • เหมาะกับมอเตอร์ไซค์ที่ไม่มีเครื่อง GPS ติดรถ
ระดับ 3 · GPS ติดรถเครื่องติดตามยานพาหนะ
  • ดึงระยะทางสะสมและตำแหน่งจากผู้ให้บริการผ่าน API หรือ webhook
  • ได้ข้อมูลต่อเนื่องโดยไม่ต้องพึ่งการกรอก
  • ต้องตรวจว่ายี่ห้อที่ใช้อยู่เปิด API ให้หรือไม่

สูตรคำนวณและเกณฑ์แจ้งเตือน

ระยะทาง = เลขไมล์สิ้นสุด − เลขไมล์เริ่มต้น

อัตราสิ้นเปลือง (กม./ลิตร) = ระยะทาง ÷ ลิตรที่เติม (แบบเติมเต็มถัง)

ต้นทุนต่อกม. = ลิตร × ราคาต่อลิตร ÷ ระยะทาง

แจ้งเตือน เมื่อ กม./ลิตร จริง ต่ำกว่า 70% ของมาตรฐาน หรือระยะทางเลขไมล์ต่างจากระยะทาง GPS เกิน 10% (ตัวเลขเกณฑ์ปรับได้)

การล็อกอินด้วยรหัสกดและสิทธิ์ผู้ใช้

ผู้ใช้แต่ละคนมีรหัส 6 หลักของตัวเอง ระบบรู้ว่าใครบันทึกรายการจากรหัสนี้ จึงต้องไม่ซ้ำกัน

ตรวจรหัส ที่ Apps Script เท่านั้น ไม่ตรวจในหน้าเว็บ เพราะคนเปิดดูโค้ดจะเห็นรหัสทั้งหมด

เก็บรหัส แบบแฮชพร้อมค่าสุ่ม (salt) ในชีต Users ไม่เก็บเป็นตัวเลขตรงๆ

แผนพัฒนาเป็นระยะ

  1. ระยะที่ 1
    ฟอร์มบันทึก คำนวณอัตโนมัติ แดชบอร์ด และรายงานบน Google Sheetsหน้าจอนี้คือต้นแบบของระยะที่ 1
  2. ระยะที่ 2
    ถ่ายรูปเลขไมล์ แล้วอ่านค่าด้วย OCR ให้ผู้ใช้ตรวจก่อนบันทึกเก็บรูปไว้เป็นหลักฐานคู่กับรายการ
  3. ระยะที่ 3
    เทียบระยะทางกับ Google Maps หรือ GPS และแจ้งเตือนเมื่อผิดปกติเริ่มจากรถที่มีปัญหาเรื่องเชื้อเพลิงบ่อยก่อน
  4. ระยะที่ 4
    รายงานรายเดือนสำหรับผู้บริหาร และกำหนดสิทธิ์ผู้ใช้ตามบทบาทผู้ขับ เจ้าหน้าที่ควบคุม ผู้ดูรายงาน
